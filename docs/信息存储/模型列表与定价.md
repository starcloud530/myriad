# 模型列表与定价

三套信息分开放。密钥见 [鉴权托管.md](./鉴权托管.md)。

## 模型 / 能力信息

一等公民是 **Capability**，不是厂商模型名。

| 阶段 | 放哪 | 不放哪 |
|---|---|---|
| 开通清单 | 仓库 `现有服务厂商模型/vendors/*.yaml`（无密钥） | 协议文件夹 |
| 运行时第一期 | `packages/gateway/src/catalog/seed.ts` 内存 catalog | yaml 运行时直读、协议包 |
| 上线后 | 同一份结构进 KV，控制台改渠道 | 每请求写 KV |

第一期**不做**全量模型索引（OpenRouter 四百个、HF 货架）。更新模型 = 改 yaml + seed，或以后控制台写 KV。

`channel.config` 只含 `secret_env` / `vendor_model` / `base_url`（及 fal 的 `edit_model`）。对外列表剥掉 config。

## 定价

第一期定价活在 Capability 上的静态 `BillingSpec`：

- `unit`：`token` / `image` / `audio_second` / `video_second` / `request`
- `cny_per_unit`：可选人民币单价快照，不是每次请求写库

控制台「计费规则」页第一期保持空态。以后控制台写 KV；官方价偶尔拉一次覆盖快照。

不要把 New API 那套「每 token 倍率」做成内核。额度计数走 Durable Object，成本账走 Analytics Engine（第一期先 console 追加）。

## 第一期四条能力

| 能力 | kind | 主渠道 | 备渠道 |
|---|---|---|---|
| `chat` | `chat` | DeepSeek `deepseek-chat` | 千问 `qwen-plus` |
| `image.generate` | `generate.image` | fal `fal-ai/gpt-image-2`；`refs[]` 走 `fal-ai/gpt-image-2/edit`（最多 16 张） | — |
| `video.generate` | `generate.video` | 火山 Seedance（异步 job） | fal MiniMax video |
| `audio.speech` | `generate.audio` | fal MiniMax Speech | — |

`complete` / `transduce` / `extract` / `score.*` / `realtime` 只留合同，第一期不接渠道。
